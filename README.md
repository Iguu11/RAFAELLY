# Rafaelly — Experiência Interativa

Projeto pessoal criado como uma experiência visual inspirada em interfaces de streaming para apresentar momentos, mensagens e lembranças de forma interativa.

## Experiência

- Seleção de perfil
- Introdução animada
- Área principal com momentos em destaque
- Cards de lembranças
- Modais com imagens e mensagens
- Carta final interativa

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Executar localmente

O projeto é estático. Abra-o usando um servidor HTTP local para garantir o carregamento correto dos arquivos:

```bash
npx serve .
```

Também é possível utilizar a extensão Live Server no VS Code.

## Observação

Este é um projeto pessoal e contém conteúdo afetivo personalizado.
