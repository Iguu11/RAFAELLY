LOVFLIX - Site homenagem Dia dos Namorados

Como editar:
1. Abra o projeto no VS Code.
2. Edite os textos no arquivo index.html.
3. Para colocar fotos de vocês, crie uma pasta chamada img e troque o fundo no style.css.

Rodar no VS Code:
- Opção simples: abrir index.html no navegador.
- Opção melhor: instalar a extensão Live Server e clicar em "Go Live".

Personalização rápida:
- Troque "Igor & Minha Namorada" pelo nome de vocês.
- Troque os textos dos cards em "Trending Now".
- Troque a carta na seção "Uma carta para você".
